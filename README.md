# Wamadat - Teaching Strategies Website

A modern, responsive website dedicated to sharing innovative teaching strategies and educational resources.

## Overview

Wamadat is an educational platform that helps teachers and educators discover and implement evidence-based teaching strategies to improve student engagement and learning outcomes.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Strategy Showcase**: Featured teaching strategies with detailed descriptions
- **Educational Resources**: Collection of teaching toolkits, case studies, and research articles
- **Contact Form**: Easy way for visitors to get in touch with inquiries
- **Smooth Navigation**: Smooth scrolling and intuitive site navigation
- **Modern Styling**: Clean, professional design with gradient elements

## Structure

wamadat/

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mohamedtaherradwan-alt/wamadat.git
   cd wamadat
   ```

2. Open `index.html` in your web browser

## Features Included

### Navigation
- Sticky header with smooth scrolling navigation
- Active section highlighting as you scroll

### Sections

1. **Hero Section**: Eye-catching introduction to the platform
2. **Teaching Strategies**: Featured strategies including:
   - Active Learning
   - Collaborative Learning
   - Differentiated Instruction
   - Problem-Based Learning

3. **Resources**: Educational materials and tools
4. **About**: Platform information
5. **Contact**: Contact form for inquiries
